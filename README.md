# LibraryApp

Консольное приложение на C# (.NET 8) для учета книг в библиотеке. Учебный проект практической подготовки по теме "Отладка проекта. Инспекция кода модулей проекта. Документирование результатов тестирования".

## Возможности

- добавление книги в библиотеку;
- выдача книги читателю;
- возврат книги в библиотеку;
- поиск книги по идентификатору;
- сообщения об ошибках при некорректных операциях: книга не найдена, книга уже выдана, книга не была выдана, повторный Id.

## Структура проекта

- LibraryApp/Book.cs: класс Book (Id, Title, Author, IsAvailable);
- LibraryApp/Library.cs: класс Library (AddBook, BorrowBook, ReturnBook, FindBook, GetBooks);
- LibraryApp/Program.cs: точка входа, демонстрация сценариев;
- LibraryApp/.editorconfig: правила именования для анализаторов кода;
- TEST_REPORT.md: отчет о тестировании.

## Требования

- .NET SDK 8.0 или новее;
- Microsoft Visual Studio 2022 или любой редактор с поддержкой C#.

## Запуск

Из командной строки:

```
git clone <адрес репозитория>
cd LibraryApp
dotnet run --project LibraryApp
```

Из Visual Studio: открыть файл LibraryApp.sln и нажать F5 (с отладкой) или Ctrl+F5 (без отладки).

## Ожидаемый результат

Программа последовательно выполняет сценарии выдачи и возврата книг, выводит сообщения об ошибках для некорректных операций и в конце печатает состояние всех книг.
